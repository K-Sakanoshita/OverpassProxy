# OverpassProxy
* Overpass APIのキャッシュサーバ

# レンタルサーバー向けキャッシュサーバ
* Overpass APIサーバーの負荷を下げるための簡易キャッシュサーバ
* さくらインターネットのレンタルサーバーを念頭にしています

# 動作内容
* クエリのBBOXを少し広めに整えて本家Overpass APIへ問い合わせる
* 返却されたデータをキャッシュし、同じクエリに対して返答する
* BBOXを広めに整えることで、キャッシュヒット率を向上させている
* クエリがキャッシュ範囲内であれば、そのキャッシュデータを返す
* キャッシュの保持期間は秒単位で設定可能（初期設定は7日間）

# 構築方法
* config_overpass.php（設定ファイル）
* www（Webルートドキュメントフォルダ）
*  +-- apiフォルダ
*    +-- overpass_proxy.php（キャッシュ本体）
*    +-- .htaccess（overpass_proxy.phpへのリダイレクト）
*    +-- cache_admin.php（キャッシュ管理画面）
